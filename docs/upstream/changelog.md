# Changelog

The current launch baseline is API-first, Script Tag second, SDK third.

## 2026 Q2

Added canonical API v1 routes, browser activation, docs-linked error envelopes, Script Tag debug diagnostics, SDK migration guidance, and compatibility aliases for existing SDK/browser paths.

## Deprecated

SDK-first onboarding language is deprecated. The SDK remains available as an advanced compatibility layer.

## Current public baseline

Interactive Try it mode, Algolia search, additional language tabs, locale versions, and productized webhook subscriptions are outside the current public API baseline.
